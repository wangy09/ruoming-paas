## 4. 模块开发规范

### 4.1 后端模块标准结构

每个业务模块必须包含以下文件：

```
module_name/
├── router.py       # 路由（APIRouter）+ 请求入参校验
├── service.py      # 业务逻辑（不含 HTTP 类型）
├── repository.py   # 数据库操作（可选，简单模块合并到 service）
├── schemas.py      # Pydantic 请求/响应模型
└── models.py       # SQLAlchemy ORM 模型
```

### 4.2 模块注册方式

```python
# app/main.py
from app.modules.auth.router import router as auth_router
from app.modules.user.router import router as user_router
from app.ai.llm.router import router as llm_router

app.include_router(auth_router, prefix="/api/v1/auth", tags=["认证"])
app.include_router(user_router, prefix="/api/v1/users", tags=["用户"])
app.include_router(llm_router, prefix="/api/v1/ai/llm", tags=["AI-LLM"])
```

### 4.3 数据库模型基类

```python
# app/core/base_model.py
from sqlalchemy import Column, BigInteger, DateTime, Boolean, func
from app.database import Base

class BaseModel(Base):
    """所有模型继承此基类"""
    __abstract__ = True

    id = Column(BigInteger, primary_key=True, autoincrement=True, comment="主键")
    created_at = Column(DateTime, default=func.now(), comment="创建时间")
    updated_at = Column(DateTime, default=func.now(), onupdate=func.now(), comment="更新时间")
    is_deleted = Column(Boolean, default=False, comment="软删除标记")
    tenant_id = Column(BigInteger, nullable=True, comment="租户ID（多租户预留）")
```

## 5. 多环境配置规范

### 5.1 环境文件分层

| 文件 | 用途 | 是否提交 Git |
|------|------|------------|
| `.env.example` | 所有变量的模板，值为空或示例值，说明每个变量用途 | ✅ 必须提交 |
| `.env.development` | 本地开发环境，连接本地 DB/Redis | ❌ `.gitignore` |
| `.env.test` | 自动化测试 / CI 环境，使用独立测试 DB | ❌ `.gitignore` |
| `.env.production` | 生产环境，**不得存本地**，通过 CI Secret / K8s Secret 注入 | ❌ 严禁提交 |

### 5.2 环境加载机制（Pydantic Settings）

```python
# app/config.py
from pydantic_settings import BaseSettings, SettingsConfigDict
from functools import lru_cache
import os

class Settings(BaseSettings):
    # ── 环境标识 ──────────────────────────────
    APP_ENV: str = "development"          # development / test / production
    DEBUG: bool = False

    # ── 数据库 ────────────────────────────────
    DATABASE_URL: str                      # 必填，启动 Fail-Fast
    REDIS_URL: str = "redis://localhost:6379/0"

    # ── 安全 ──────────────────────────────────
    SECRET_KEY: str                        # 必填
    JWT_ALGORITHM: str = "HS256"
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 30
    REFRESH_TOKEN_EXPIRE_DAYS: int = 7

    # ── AI 配置（默认值，可被 config_center 覆盖） ──
    AI_DEFAULT_PROVIDER: str = "zhuilu"
    AI_DEFAULT_TEMPERATURE: float = 0.7
    AI_DEFAULT_MAX_TOKENS: int = 2048
    ZHUILU_API_KEY: str = ""
    ZHUILU_BASE_URL: str = ""
    OPENAI_API_KEY: str = ""

    # ── 文件存储 ──────────────────────────────
    STORAGE_BACKEND: str = "local"        # local / oss / minio
    OSS_BUCKET: str = ""
    OSS_ACCESS_KEY: str = ""
    OSS_SECRET_KEY: str = ""

    model_config = SettingsConfigDict(
        # 自动加载 .env.{APP_ENV} 文件，优先级：环境变量 > .env.{env} > 默认值
        env_file=(
            ".env",
            f".env.{os.getenv('APP_ENV', 'development')}",
        ),
        env_file_encoding="utf-8",
        extra="ignore",
    )

@lru_cache
def get_settings() -> Settings:
    """单例，整个应用共享同一份 Settings 实例"""
    return Settings()

settings = get_settings()
```

### 5.3 各环境关键差异

| 变量 | development | test | production |
|------|-------------|------|------------|
| `DEBUG` | `True` | `False` | `False` |
| `DATABASE_URL` | 本地 PG | 测试专用 PG（独立库） | 生产 PG（连接池） |
| `REDIS_URL` | 本地 Redis DB0 | 本地 Redis DB1 | 生产 Redis Cluster |
| `STORAGE_BACKEND` | `local` | `local` | `oss` |
| `AI_DEFAULT_PROVIDER` | `openai`（测试用）| `openai` | `zhuilu` |
| `SECRET_KEY` | 任意固定值 | 任意固定值 | 强随机，通过 Secret 注入 |

### 5.4 生产环境安全要求

```bash
# ❌ 禁止做法
git add .env.production          # 严禁提交生产配置
SECRET_KEY=123456                # 弱密钥

# ✅ 正确做法（GitHub Actions 示例）
# 通过 CI Secret 注入，不落磁盘
env:
  SECRET_KEY: ${{ secrets.PROD_SECRET_KEY }}
  DATABASE_URL: ${{ secrets.PROD_DATABASE_URL }}

# K8s Secret 挂载示例
envFrom:
  - secretRef:
      name: ruoming-saas-secrets
```

> **Fail-Fast 原则**：`DATABASE_URL`、`SECRET_KEY` 等必填项未配置时，应用启动即抛出 `ValidationError`，而不是运行时才报错。Pydantic Settings 的无默认值字段自动实现此效果。
