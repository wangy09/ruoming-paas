# 【首发】告别重复造轮子：若茗 PaaS 让企业级 AI 应用 2 周上线

> 一个开发者的自白

---

## 你是不是也这样？

去年接了一个企业 CRM 的活儿，客户要求：权限、多租户、操作日志、第三方集成、AI 问答……

我掐指一算：光基础设施就得做 **3 个月**。

- 权限系统（RBAC + 按钮级）→ 4 周
- 多租户数据隔离 → 2 周
- JWT 认证 + Token 刷新 → 1 周
- 操作审计日志 → 1 周
- 接口限流熔断 → 1 周
- 接入大模型 + Agent → 4 周
- 知识库 RAG → 3 周
- 配置中心 → 1 周
- 结构化日志 + 链路追踪 → 1 周

**合计：18 周。**

客户说："这系统很复杂吗？不就是几个增删改查？"

我竟无言以对。

---

## 问题出在哪？

不是我们不够努力，而是每个企业应用都在 **重复造同一套轮子**：

> 权限、多租户、认证、审计、限流、AI 接入……这些跟业务无关的基础设施，占了 70% 的开发时间。

更憋屈的是：
- 每个项目造的轮子质量参差不齐
- A 项目的权限系统不能复用到 B 项目
- AI 能力每个项目都要从头接入一遍
- 团队成员在重复劳动中逐渐消磨热情

---

## 若茗 PaaS 是什么？

**开箱即用的企业级 AI 应用开发底座。**

你只需要写业务代码，其余基础设施——权限、多租户、AI、日志、限流、配置中心——全部开箱即用。

**把 18 周的基础设施开发，压缩到 0。**

## 核心能力一览

**🏗️ 企业级底座，生产可用**

> 🔐 多租户隔离：数据库行级隔离，应用层 + 兜底双重防护，A 租户查不到 B 租户的数据
>
> 🛡️ 细粒度权限：RBAC + 角色继承，精细到按钮、表格列，前后端权限数据同步
>
> 🔑 统一认证：JWT + Refresh Token 轮换，支持 API Key、SSO、企微/钉钉集成
>
> 📋 操作审计：所有写操作自动记录变更前后快照，谁改了什么一目了然
>
> ⚙️ 配置中心：四级分层（全局→租户→应用→用户），修改后自动生效，无需重启
>
> 📁 文件 & 集成：文件中心、飞书/钉钉/企业微信通讯录同步

**🤖 原生 AI，不是插件**

> 🧠 统一模型网关：追鹿大模型、OpenAI 兼容、本地 Ollama，随时切换
>
> 🤝 AI Agent 编排：单 Agent / Multi-Agent 工作流，支持工具调用、流式 SSE 输出
>
> 🎯 场景路由：闲聊、专业问答、任务执行、RAG 检索、创意写作……自动匹配最优模型和参数
>
> 📚 知识库 RAG：向量 + BM25 + Rerank 混合检索，比纯向量检索准确率提升 30%+
>
> ✏️ Prompt 版本化：草稿 → 发布 → 回滚，变量插值渲染，Agent 可锁定版本

**🔧 开发效率翻倍**

> ⚡ 代码生成器：一键生成 Model / Schema / API / 前端页面
>
> 🧩 模块化设计：L0-L4 分层，按需启用，新模块插件式接入
>
> 📡 事件总线：持久化事件、重试、死信队列，跨模块解耦
>
> 📝 结构化日志：JSON 日志 + RequestID 全链路追踪
>
> 📊 异步导入导出：百万行流式 Excel，进度实时推送

## 3 步跑起来

```bash
# 1. 克隆项目
git clone <repository-url>
cd RuoMingPaas

# 2. 复制环境配置
cp backend/.env.example backend/.env.development

# 3. 一键启动
bash scripts/start.sh dev
```

启动后访问：
