## 这是什么？

若茗 PaaS 是一套**生产可用的企业级应用开发底座**。你在它上面开发业务模块，底层的权限、多租户、AI、日志、限流等全部已经帮你做好了。

**一句话**：你只需要写业务代码，其余基础设施交给若茗。

---

## 为什么用若茗？

大多数企业应用开发，70% 的时间花在和业务无关的基础设施上：

- 权限系统怎么设计？角色继承、按钮级权限怎么做？
- 多租户如何隔离？怎么防止 A 租户查到 B 租户的数据？
- 接入大模型，Agent 怎么编排？知识库怎么接？
- 操作日志、审计怎么记？
- 限流、熔断怎么配？

**若茗把这些全部做好了，开箱即用。**

## 核心能力一览

### 🏗️ 企业级底座
| 能力 | 说明 |
|------|------|
| **多租户隔离** | 数据库行级隔离，`TenantAwareRepository` 自动注入，应用层+兜底双重防护 |
| **细粒度权限** | RBAC + 角色继承，精细到按钮、表格列级别，前后端权限数据同步 |
| **统一认证** | JWT（PyJWT）+ Refresh Token 轮换，支持 API Key、SSO/OIDC/企微/钉钉 |
| **操作审计** | 所有写操作自动记录变更前后快照，登录日志、安全事件完整可查 |
| **配置中心** | 四级分层（全局→租户→应用→用户），支持动态下发，无需重启 |
| **资源与集成** | 文件中心、集成中心、飞书/钉钉/企业微信通讯录同步 |
| **计划任务** | 独立调度服务，统一管理定时任务和执行日志 |

### 🤖 原生 AI 能力
| 能力 | 说明 |
|------|------|
| **统一模型网关** | 支持模型配置、OpenAI 兼容协议、默认模型、熔断和回退 |
| **AI Agent 编排** | 单 Agent / Multi-Agent 工作流，支持工具调用、流式输出 |
| **场景路由** | 混合模式（前端显式→规则引擎→模型分类），自动匹配 Prompt 和参数 |
| **知识库 RAG** | 混合检索（向量 + BM25 + Rerank + RRF），支持多格式文档 |
| **Prompt 版本化** | 草稿→发布→回滚，变量插值，Agent 可锁定指定版本 |

### 🔧 开发效率
| 能力 | 说明 |
|------|------|
| **代码生成器** | 一键生成 CRUD 的 Model/Schema/API/前端页面/测试用例 |
| **模块化设计** | L0-L4 分层，按需启用，新模块插件式接入 |
| **事件总线** | 持久化事件、重试、死信队列，跨模块解耦 |
| **异步导入导出** | 百万行流式 Excel/CSV，进度实时推送 |
| **结构化日志** | structlog JSON 日志，RequestID 全链路追踪，非阻塞写入 |

```

部署：Docker Compose  ·  Nginx
```

## 快速开始

```bash
# 1. 克隆项目
git clone <your-repository-url>
cd RuoMingPaas

# 2. 复制环境配置
cp backend/.env.example backend/.env.development

# 3. 一键启动（开发环境）
bash scripts/start.sh dev

# 4. 访问
# 前端：http://localhost:3000
# API 文档：http://localhost:8000/api/docs
# 默认账号：admin / ruoming@2026
```

> 详细步骤见 [01_快速启动.md](./01_快速启动.md)

## 模块层级说明

```
L0 核心框架   ── 不可禁用，所有模块的基础（配置/数据库/安全/异常）
L1 基础服务   ── 不可禁用，企业应用必备（认证/用户/权限/租户/审计）
L2 通用引擎   ── 按需启用（事件总线/定时任务/导入导出/搜索/审批流）
L3 通用模块   ── 按需启用（消息通知/文件管理/字典/监控/SSO/代码生成）
L4 高级能力   ── 按需启用（灰度发布/报表大屏/国际化/数据合规）
AI 模块       ── 按需启用（LLM网关/Agent/知识库RAG/工具链/Prompt管理）
```

## 适用场景

✅ **适合**
- 企业内部系统（OA、CRM、ERP 等）快速搭建
- 基于 AI 能力的企业应用 / SaaS 产品开发
- 需要多租户隔离的 B 端产品
- 中小团队快速交付，避免重复造轮子

❌ **不适合**
- 纯前端/静态站点项目
- 极简小工具（杀鸡用牛刀）
- 需要完全自定义技术栈的项目
