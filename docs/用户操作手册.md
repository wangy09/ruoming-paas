## 1. 系统概述

若茗 PaaS 是一款企业级 AI 原生平台，提供：

- **智能对话**：基于大模型的 AI 对话能力
- **知识管理**：文档向量化与 RAG 检索
- **代码生成**：快速生成业务模块代码
- **权限管理**：完整的 RBAC 权限体系
- **系统监控**：实时监控系统运行状态

### 主要导航

系统左侧为功能导航菜单，主要模块包括：

| 模块 | 路径 | 说明 |
|------|------|------|
| 工作台 | /dashboard | 个人工作入口 |
| 用户管理 | /system/users | 管理系统用户 |
| 角色授权 | /system/role-permission | 配置用户权限 |
| AI 对话 | /ai/chat | 与 AI 对话 |
| Agent 管理 | /ai/agents | 配置 AI 智能体 |
| 知识库 | /ai/knowledge | 管理 AI 知识库 |
| 代码生成 | /dev/codegen | 生成业务代码 |
| 消息中心 | /message/inbox | 查看通知消息 |

## 2. 登录与基础操作

### 2.1 登录系统

1. 打开浏览器，访问系统地址
2. 输入用户名和密码
3. 点击「登录」按钮

### 2.2 界面布局

系统界面分为以下区域：

- **顶部导航栏**：显示用户信息、消息图标
- **左侧菜单**：功能导航入口
- **主内容区**：显示当前页面内容
- **AI 助手按钮**：右下角浮动的 AI 机器人图标

### 2.3 常用操作

- **展开/收起侧边栏**：点击顶部菜单图标
- **打开新标签页**：点击侧边栏菜单自动打开
- **关闭标签页**：双击标签或点击 × 按钮
- **切换主题**：点击右上角用户头像 → 主题设置

## 3. 工作台

工作台是用户登录后的首页，提供快速入口和数据概览。

### 3.1 工作台概览

工作台根据用户角色显示不同内容：

- **统计卡片**：显示未读消息、待办任务等
- **快捷入口**：常用功能的快速跳转
- **最近活动**：最近的操作记录
- **系统公告**：最新通知

### 3.2 快捷入口

常用快捷入口包括：

- 用户管理：维护账号、角色和状态
- 角色授权：配置菜单、按钮和数据范围
- 配置中心：管理运行时业务配置
- 消息中心：公告与站内消息
- Agent 管理：创建和维护智能体
- 知识库：管理文档和向量索引
- 代码生成器：生成基础业务模块

## 4. AI 智能助手

右下角的 AI 机器人是系统智能助手，可随时为您提供帮助。

### 4.1 打开 AI 助手

1. 点击右下角的 **🤖 机器人图标**

3. 首次使用会显示欢迎语

- **工作台**：跳转到工作台页面

在对话框中输入指令即可快速导航：

**支持的指令示例：**

可以向 AI 助手提问系统使用问题：

**示例问题：**

- `如何创建新用户？`

- `如何配置 AI 模型？`
- `如何使用知识库？`

- 点击面板右上角的 × 按钮
- 或点击面板外部区域

## 5. 用户管理

### 5.1 查看用户列表

路径：**系统管理 → 用户管理**

**功能说明：**

- 显示所有系统用户
- 支持按用户名、部门、状态筛选
- 支持分页浏览

### 5.2 新增用户

1. 点击右上角「新增用户」按钮
2. 填写用户信息：
   - **用户名**（必填）：登录账号
   - **姓名**（必填）：真实姓名
   - **手机号**：手机号码
   - **邮箱**：电子邮箱
   - **部门**：所属部门
   - **角色**：分配角色
   - **状态**：启用/禁用
3. 点击「确定」保存

### 5.3 编辑用户

1. 在用户列表中找到目标用户
2. 点击操作列的「编辑」按钮
3. 修改用户信息
4. 点击「确定」保存

### 5.4 分配角色

1. 在用户列表中找到目标用户
2. 点击操作列的「分配角色」按钮
3. 在弹出的角色选择窗口中勾选角色
4. 点击「确定」保存

### 5.5 禁用/启用用户

1. 在用户列表中找到目标用户
2. 点击操作列的「禁用」或「启用」按钮
3. 确认操作

### 5.6 重置密码

1. 在用户列表中找到目标用户
2. 点击操作列的「重置密码」按钮
3. 系统将生成临时密码
4. 复制密码并告知用户

## 7. 角色与权限

### 7.1 角色管理

路径：**系统管理 → 角色管理**

#### 新增角色

1. 点击「新增角色」按钮
2. 填写角色信息：
   - **角色名称**（必填）
   - **角色编码**（必填）
   - **数据权限范围**：
     - 全部数据权限
     - 本部门及以下
     - 本部门
     - 仅本人
     - 自定义
   - **备注**
3. 点击「确定」保存

#### 编辑角色

1. 在角色列表中找到目标角色
2. 点击操作列的「编辑」按钮
3. 修改角色信息
4. 点击「确定」保存

### 7.2 角色授权

路径：**系统管理 → 角色授权**

#### 配置权限

1. 在左侧选择要配置的角色
2. 在中间菜单树中勾选菜单权限
3. 在右侧配置数据权限范围
4. 点击「保存」

**权限类型：**

- **菜单权限**：控制可见的导航菜单
- **按钮权限**：控制可操作的功能按钮
- **数据权限**：控制可查看的数据范围

## 8. 通知与消息

### 8.1 通知管理

路径：**消息中心 → 通知管理**

#### 发布通知

1. 点击「新增通知」按钮
2. 填写通知信息：
   - **标题**（必填）
   - **内容**（必填）
   - **类型**：公告/通知/提醒

**功能说明：**

- 查看所有接收到的通知

- 按类型筛选
- 批量删除

## 9. AI 对话

路径：**AI 管理 → AI 对话**

### 9.1 开始对话

1. 在左侧选择或创建对话
2. 在输入框输入问题
3. 按 Enter 或点击发送按钮
4. AI 将流式回复

### 9.2 选择 Agent

1. 点击顶部的 Agent 选择器
2. 从下拉列表选择：
   - 闲聊助手：轻松对话
   - 专业分析师：数据分析
   - 编程助理：代码辅助
   - 知识库问答：知识查询
   - 创意写手：文案创作

### 9.3 对话功能

- **新建对话**：开始新的对话
- **历史对话**：查看历史记录
- **停止生成**：中断 AI 回复
- **重新生成**：再次生成回复
- **复制回复**：复制 AI 的回答
- **删除对话**：删除不需要的对话

### 9.4 使用提示

- 支持多轮对话，AI 会记住上下文
- 可以使用 @ 引用特定知识库
- 支持 Markdown 格式回复

## 10. AI 模型管理

路径：**AI 管理 → 模型管理**

### 10.1 接入模型

1. 点击「接入模型」按钮
2. 填写模型信息：
   - **供应商**：追鹿/阿里云/火山引擎/自定义
   - **模型名称**（必填）
   - **API 地址**（必填）
   - **API Key**（必填，加密存储）
   - **默认参数**
3. 点击「测试连接」验证
4. 点击「确定」保存

### 10.2 模型配置

**常见供应商配置：**

- **追鹿**：默认配置，无需填写 API Key
- **阿里云百炼**：填写 DashScope API Key
- **火山引擎**：填写 Ark API Key
- **自定义**：填写兼容 OpenAI 的接口

### 10.3 设置默认模型

1. 在模型列表中找到目标模型
2. 点击「设为默认」按钮
3. 其他 Agent 将默认使用此模型

## 11. Agent 管理

路径：**AI 管理 → Agent 管理**

### 11.1 新建 Agent

1. 点击「新建 Agent」按钮
2. 填写 Agent 信息：
   - **名称**（必填）
   - **描述**
   - **头像**
   - **绑定模型**
   - **系统提示词**（必填）
   - **默认场景**
   - **最大对话轮次**
   - **温度**：0-1，越大越随机
3. 点击「下一步」配置工具和知识库
4. 点击「确定」创建

### 11.2 Agent 场景

| 场景 | 说明 |
|------|------|
| chitchat | 闲聊，轻松对话 |
| professional | 专业问答，结合知识库 |
| task | 任务执行，调用工具 |
| rag | 检索增强生成 |
| creative | 创意写作 |

### 11.3 配置系统提示词

系统提示词决定 AI 的角色和能力：

**示例：**

```
你是若茗 PaaS 系统的智能助手。
你的职责：
1. 回答系统使用问题
2. 指导用户操作
3. 提供最佳实践建议

回答风格：专业、简洁、友好
```

### 11.4 绑定知识库

1. 在 Agent 编辑页面的「知识库」tab
2. 点击「添加知识库」
3. 选择已创建的知识库
4. 调整检索参数

### 11.5 绑定工具

1. 在 Agent 编辑页面的「工具」tab
2. 点击「添加工具」
3. 选择可用工具
4. 保存配置

### 11.6 Agent 调试

1. 点击 Agent 列表的「调试」按钮
2. 在测试面板输入问题
3. 查看回复效果
4. 根据效果调整提示词

## 12. 知识库

路径：**AI 管理 → 知识库**

### 12.1 新建知识库

1. 点击「+ 新建知识库」按钮
2. 填写知识库信息：
   - **名称**（必填）
   - **描述**
   - **向量模型**
3. 点击「确定」创建

### 12.2 上传文档

1. 进入知识库详情页
2. 点击「上传文档」按钮
3. 选择文件：
   - 支持格式：PDF、Word、Markdown、TXT、HTML
   - 单文件大小：≤ 20MB
4. 等待解析完成

### 12.3 文档管理

- **查看列表**：点击知识库进入详情
- **删除文档**：点击文档旁的删除按钮
- **重新解析**：点击「重新解析」按钮

### 12.4 知识库使用

1. 在 Agent 编辑页面绑定知识库
2. 配置检索参数：
   - 召回数量：返回的相关片段数
   - 相似度阈值：最低匹配度
3. AI 对话时自动检索相关内容

### 12.5 向量化说明

系统使用 pgvector 存储向量：

- 文档被切分为合适的片段
- 每个片段被转换为向量
- 查询时进行相似度检索
- 返回最相关的片段给 LLM

## 16. 常见问题解答

### 账户相关

**Q: 忘记密码怎么办？**

A: 联系系统管理员重置密码。

**Q: 如何修改密码？**

A: 点击右上角用户头像 → 个人设置 → 修改密码。

**Q: 账号被禁用了怎么办？**

A: 联系管理员启用账号。

### 权限相关

**Q: 看不到某个菜单？**

A: 请联系管理员为您分配相应角色和权限。

**Q: 权限变更后需要重新登录吗？**

A: 是的，权限变更后需重新登录生效。

**Q: 如何申请权限？**

A: 联系管理员，说明需要的功能和理由。

### AI 功能相关

**Q: AI 回答不准确怎么办？**

A: 可以：
1. 在 Agent 管理中优化系统提示词
2. 补充相关知识库文档
3. 调整温度参数降低随机性

**Q: 如何让 AI 回答更专业？**

A: 
1. 绑定专业知识库
2. 设置为 professional 场景
3. 优化系统提示词

**Q: AI 助手支持哪些导航指令？**

A: 支持的指令格式：
- `打开XXX`
- `进入XXX`
- `查看XXX`
- `去XXX`

### 知识库相关

**Q: 支持上传哪些格式？**

A: 支持 PDF、Word、Markdown、TXT、HTML 等格式。

**Q: 文档解析失败怎么办？**

A: 可能原因：
1. 文件格式不支持
2. 文件过大（≤ 20MB）
3. 文档内容为空

**Q: 如何更新知识库？**

A: 重新上传或更新文档即可，系统会重新向量化。

### 代码生成相关

**Q: 生成的代码在哪里？**

A: 选择保存路径后，代码会直接写入指定目录。

**Q: 如何避免覆盖现有代码？**

A: 默认跳过已存在的文件，可手动勾选覆盖。

2. 查看系统监控
3. 清理缓存
4. 联系运维人员

A: 系统管理员可在审计日志中查看所有操作记录。
