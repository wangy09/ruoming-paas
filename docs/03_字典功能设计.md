# 字典功能设计

## 1. 功能概述

字典功能用于管理系统中的静态数据，如性别、状态、部门类型等。通过字典管理，可在不修改代码的情况下动态配置下拉选项。

## 2. 数据模型设计

### 2.1 字典类型表（sys_dict_type）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| name | VARCHAR(64) | 字典类型名称（如"性别"） |
| code | VARCHAR(64) | 字典类型编码（唯一，如"sex"） |
| description | TEXT | 描述说明 |
| sort | INT | 排序 |
| status | SMALLINT | 状态：1正常 0停用 |
| is_system | BOOLEAN | 是否系统内置 |
| tenant_id | BIGINT | 所属租户 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |
| is_deleted | BOOLEAN | 逻辑删除 |

### 2.2 字典项表（sys_dict_item）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| type_id | BIGINT | 所属字典类型 ID |
| label | VARCHAR(64) | 显示标签（如"男"） |
| value | VARCHAR(128) | 实际值（如"1"） |
| description | TEXT | 描述说明 |
| sort | INT | 排序 |
| status | SMALLINT | 状态：1正常 0停用 |
| is_default | BOOLEAN | 是否默认值 |
| css_class | VARCHAR(128) | 样式类（用于前端显示不同颜色） |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |
| is_deleted | BOOLEAN | 逻辑删除 |

## 3. API 设计

### 3.1 字典类型 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/dict/types | 获取字典类型列表 |
| GET | /api/v1/dict/types/{id} | 获取字典类型详情（含字典项） |
| POST | /api/v1/dict/types | 创建字典类型 |
| PUT | /api/v1/dict/types/{id} | 更新字典类型 |
| DELETE | /api/v1/dict/types/{id} | 删除字典类型 |

### 3.2 字典项 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/dict/items | 获取字典项列表（按类型筛选） |
| POST | /api/v1/dict/items | 创建字典项 |
| PUT | /api/v1/dict/items/{id} | 更新字典项 |
| DELETE | /api/v1/dict/items/{id} | 删除字典项 |

### 3.3 前端使用 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/dict/code/{code} | 根据字典编码获取字典项（前端常用） |

## 4. 初始化数据

### 4.1 默认字典类型

| 编码 | 名称 | 说明 |
|------|------|------|
| user_status | 用户状态 | 正常、禁用、锁定 |
| common_status | 通用状态 | 启用、停用 |
| data_scope | 数据权限范围 | 全部数据、本部门、本部门及子部门、仅本人、自定义部门 |
| tenant_status | 租户状态 | 正常、禁用、过期 |
| agent_status | Agent 状态 | 运行中、停止、异常 |

### 4.2 字典项数据

```

- 2: 锁定

通用状态（common_status）：
```

## 5. 前端使用方式

### 5.1 通用 Hook（推荐）

框架封装了通用的字典 Hook，使用时只需传入字典编码：

```typescript
// src/hooks/useDict.ts

export function useDictItems(dictCode: string) {
  const items = ref<any[]>([])
  const loading = ref(false)

  async function load() {
    loading.value = true
    try {
      const res = await getDictItems(dictCode)
      items.value = res.data
    } finally {
      loading.value = false
    }
  }

  return { items, loading, reload: load }
}

export function useDictLabel(dictCode: string) {
  const { items } = useDictItems(dictCode)
  return (value: string | number) => {
    const item = items.value.find(i => String(i.value) === String(value))
    return item?.label || value
  }
}

// 预设常用字典 Hook
export const useCommonStatus = () => useDictItems('common_status')
export const useUserStatus = () => useDictItems('user_status')
export const useDataScope = () => useDictItems('data_scope')
```

### 5.2 使用示例

```vue
<script setup lang="ts">
import { useUserStatus, useDataScope } from '@/hooks/useDict'

const { options: userStatusOptions, label: getUserStatusLabel } = useUserStatus()
const { options: scopeOptions, label: getScopeLabel } = useDataScope()
</script>

<template>
  <el-table-column prop="status" label="状态">
    <template #default="{ row }">
      {{ getUserStatusLabel(row.status) }}
    </template>
  </el-table-column>

  <el-select v-model="form.dataScope">
    <el-option
      v-for="item in scopeOptions"
      :key="item.value"
      :label="item.label"
      :value="item.value"
    />
  </el-select>
</template>
```
