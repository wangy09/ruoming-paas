# 10 开发规范

## 1. 后端编码规范

### 1.1 Python 规范

- Python ≥ 3.11，使用 `uv` 管理依赖
- 代码风格：`ruff`（格式化 + Lint）
- 类型注解：所有函数签名必须有类型注解
- 命名规范：`snake_case` 文件名和变量名，`PascalCase` 类名

```python
# ✅ 正确示例
async def get_user_by_id(user_id: int, db: AsyncSession) -> User | None:
    result = await db.execute(select(User).where(User.id == user_id))
    return result.scalar_one_or_none()

# ❌ 错误示例
async def getUser(id, db):
    ...
```

### 1.2 模块开发步骤

新增一个业务模块的标准流程：

```
1. 在 app/modules/ 或 app/ai/ 下创建模块目录
2. 定义 models.py（继承 BaseModel）
3. 编写 schemas.py（Request/Response Pydantic 模型）
4. 实现 repository.py（继承 TenantAwareRepository）
5. 实现 service.py（业务逻辑）
6. 定义 router.py（添加权限依赖 + 操作日志装饰器）
7. 在 app/main.py 注册路由
8. 执行 alembic revision --autogenerate 生成迁移文件
9. 在 sys_permission 表插入权限数据
10. 在前端 src/api/ 新增对应接口文件
11. 在前端 src/views/ 新增页面
```

## 2. 前端编码规范

### 2.1 组件规范

- 所有组件使用 `<script setup lang="ts">` + Composition API
- Props 必须有 TypeScript 类型定义
- 组件文件名使用 PascalCase（`UserList.vue`）
- 页面级组件放 `views/`，复用组件放 `components/`

### 2.2 API 调用规范

```typescript
// ✅ 统一在 src/api/ 中定义，页面中引用
// src/api/user.ts
import request from '@/utils/request'
import type { UserListParams, UserInfo, CreateUserData } from '@/types/user'

export const getUserList = (params: UserListParams) =>
  request.get<PageData<UserInfo>>('/api/v1/users', { params })

export const createUser = (data: CreateUserData) =>
  request.post<UserInfo>('/api/v1/users', data)

// ❌ 不要在组件/页面中直接写 axios.get(...)
```

### 2.3 权限使用规范

```vue
<!-- 按钮权限三种方式，推荐 v-permission 指令 -->

<!-- 方式1（推荐）：指令 -->
<el-button v-permission="'system:user:create'">新增</el-button>

<!-- 方式2：组件 -->
<HasPermission code="system:user:delete">
  <el-button type="danger">删除</el-button>
</HasPermission>

<!-- 方式3：编程式（适合复杂逻辑） -->
<script setup>
const { hasButton } = usePermission()
const showExport = hasButton('system:user:export')
</script>
```

## 3. Git 规范

### 3.1 分支规范

```
main          生产分支，保护分支，只接受 PR 合并
develop       开发集成分支
feature/xxx   新功能开发
fix/xxx       Bug 修复
hotfix/xxx    紧急生产修复
release/x.x.x 发布准备
```

### 3.2 Commit Message 规范（Conventional Commits）

```
feat: 新增用户批量导入功能
fix: 修复角色权限分配后缓存未清除问题
docs: 更新 AI 模块设计文档
refactor: 重构权限校验中间件
perf: 优化用户列表查询性能
test: 添加权限模块单元测试
chore: 升级 FastAPI 到 0.111.0
```

- **不复制 django-vue-admin 源码**：可参考其功能设计思路，但所有代码独立实现

- 商业项目使用需自行评估依赖库商业授权条款
