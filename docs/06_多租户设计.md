# 06 多租户设计

## 1. 租户隔离策略

本框架采用**共享数据库 + 应用层行级隔离**策略：

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| 独立数据库 | 完全隔离 | 成本高，运维复杂 | 金融/医疗等强合规 |
| 独立 Schema | 较好隔离 | Schema 管理复杂 | 中等规模 SaaS |
| **共享库行级隔离** ✅ | 成本低，易维护 | 数据隔离靠应用层 | 大多数 PaaS/SaaS 场景 |

> **说明**：本框架使用应用层过滤（Repository 基类自动注入 `tenant_id` 条件），而非 PostgreSQL 原生 RLS（Row-Level Security）。两种方案都可实现行级隔离，应用层方案更易于调试和维护，适合快速迭代的 PaaS/SaaS 项目。如需更强的隔离保障，可在 PostgreSQL 层叠加开启 RLS 作为兜底。

## 4. 超级管理员与租户管理员权限边界

> **v2 新增**：明确两种管理员的权限边界，防止越权设计。

### 4.1 角色定义

| 角色 | 标识 | 权限范围 | 特点 |
|------|------|---------|------|
| **超级管理员** | `is_superplatform=True` | 所有租户、平台级配置 | 不属于任何租户（`tenant_id=NULL`） |
| **租户管理员** | 角色 code=`tenant:admin` | 仅本租户内 | 属于某租户，最高权限 |
| **普通用户** | 普通角色 | 本租户内按角色权限 | 属于某租户 |

### 4.2 超级管理员权限

```python
# 超级管理员（superplatform）
# - 可查看/管理所有租户列表
# - 可进入任意租户查看数据（运维/支持场景，需记录操作审计日志）
# - 可修改租户配额、套餐
# - 可强制禁用租户
# - 无法修改租户内业务数据（防止越权）

# 数据访问规则：
# - 平台管理 API（/api/v1/admin/*）：要求 is_superplatform=True，不过滤 tenant_id
# - 租户业务 API（/api/v1/*）：超管代入某租户时，必须显式指定 tenant_id，且记录审计日志
```

```python
# app/core/deps.py

async def get_current_user(token: str = Depends(oauth2_scheme), db = Depends(get_db)):
    payload = verify_token(token)
    user = await UserService(db).get_by_id(payload["sub"])
    if not user or not user.status:
        raise HTTPException(status_code=401)
    return user

def require_superplatform():
    """仅超级管理员可访问的接口"""
    async def checker(current_user = Depends(get_current_user)):
        if not current_user.is_superplatform:
            raise HTTPException(status_code=403, detail="需要平台超级管理员权限")
        return current_user
    return checker

def require_tenant_admin():
    """租户管理员及以上可访问"""
    async def checker(current_user = Depends(get_current_user),
                      perm_service = Depends()):
        if current_user.is_superplatform:
            return current_user
        has_role = await perm_service.has_role(current_user.id, "tenant:admin")
        if not has_role:
            raise HTTPException(status_code=403, detail="需要租户管理员权限")
        return current_user
    return checker
```

### 4.3 超管代入租户访问（审计模式）

```python
# 超管需要进入某租户排查问题时，通过 X-Tenant-Impersonate 头指定租户
# 所有此类访问自动记录到审计日志

class TenantMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        tenant_id, impersonated = await self._resolve_tenant(request)
        request.state.tenant_id = tenant_id
        request.state.tenant_impersonated = impersonated
        structlog.contextvars.bind_contextvars(tenant_id=tenant_id)

        response = await call_next(request)

        # 超管代入租户：写审计日志
        if impersonated:
            asyncio.create_task(
                AuditLogService.record(
                    event="superadmin_impersonate_tenant",
                    tenant_id=tenant_id,
                    user_id=request.state.user_id,
                    path=request.url.path,
                )
            )
        return response

    async def _resolve_tenant(self, request: Request) -> tuple[int | None, bool]:
        token = self._extract_token(request)
        user_is_superplatform = False

        if token:
            payload = decode_token_without_verify(token)
            user_is_superplatform = payload.get("is_superplatform", False)

            # 超管代入指定租户
            if user_is_superplatform:
                impersonate_code = request.headers.get("X-Tenant-Impersonate")
                if impersonate_code:
                    tid = await get_tenant_id_by_code(impersonate_code)
                    return tid, True
                # 超管未指定租户，不绑定 tenant_id（访问平台级接口）
                return None, False

            if tenant_id := payload.get("tenant_id"):
                return tenant_id, False

        # 从请求头/域名解析
        if tenant_code := request.headers.get("X-Tenant-Code"):
            return await get_tenant_id_by_code(tenant_code), False

        host = request.headers.get("host", "")
        subdomain = host.split(".")[0]
        return await get_tenant_id_by_code(subdomain), False
```

## 5. Repository 层自动过滤（含兜底防护）

> **v2 新增**：原方案中，如果某个 Repository 忘记继承 `TenantAwareRepository`，会产生跨租户越权漏洞。本版本增加**全局兜底检查**：在中间件层面，对返回数据中包含 `tenant_id` 字段但与当前请求不匹配的情况进行告警。

```python
# app/core/base_repository.py
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
import structlog

logger = structlog.get_logger("security")

class TenantAwareRepository:
    """
    所有 Repository 必须继承此类（框架级约束）
    自动注入 tenant_id 过滤条件，防止跨租户数据访问
    """
    def __init__(self, db: AsyncSession, tenant_id: int | None = None):
        self.db = db
        self.tenant_id = tenant_id

    def _base_query(self, model):
        query = select(model).where(model.is_deleted == False)
        if self.tenant_id is not None:
            # 强制注入 tenant_id 过滤
            if not hasattr(model, 'tenant_id'):
                logger.warning(
                    "model_missing_tenant_id",
                    model=model.__name__,
                    tenant_id=self.tenant_id,
                )
            else:
                query = query.where(model.tenant_id == self.tenant_id)
        return query

    async def get_by_id(self, model, record_id: int):
        query = self._base_query(model).where(model.id == record_id)
        result = await self.db.execute(query)
        obj = result.scalar_one_or_none()

        # 兜底检查：即使漏了 tenant_id 过滤，也在此处拦截
        if obj and self.tenant_id and hasattr(obj, 'tenant_id'):
            if obj.tenant_id != self.tenant_id:
                logger.error(
                    "cross_tenant_access_blocked",
                    model=model.__name__,
                    record_id=record_id,
                    record_tenant_id=obj.tenant_id,
                    request_tenant_id=self.tenant_id,
                )
                return None  # 拒绝跨租户访问

        return obj
```

## 6. 配额管理

### 6.1 配额类型与实时检查

```python
# app/modules/tenant/quota.py

class TenantQuotaService:
    """租户配额检查与用量统计"""

    async def check_user_quota(self, tenant_id: int, db) -> bool:
        """检查是否可以新增用户"""
        tenant = await TenantRepository(db).get_by_id(tenant_id)
        current_count = await UserRepository(db, tenant_id).count_active()
        if current_count >= tenant.max_users:
            raise QuotaExceededError(f"用户数已达上限 {tenant.max_users}，请升级套餐")
        return True

    async def check_api_quota(self, tenant_id: int, db, redis) -> bool:
        """检查当日 API 调用次数（Redis 计数器）"""
        today = datetime.utcnow().strftime("%Y-%m-%d")
        key = f"quota:api:{tenant_id}:{today}"
        count = await redis.incr(key)
        await redis.expire(key, 86400)  # TTL = 1天

        tenant = await TenantRepository(db).get_by_id(tenant_id)
        if count > tenant.max_api_calls_day:
            raise QuotaExceededError("今日 API 调用次数已达上限")
        return True

    async def check_ai_token_quota(self, tenant_id: int, tokens: int, db, redis) -> bool:
        """检查并消耗 AI Token 配额（调用前预检）"""
        today = datetime.utcnow().strftime("%Y-%m-%d")
        key = f"quota:ai_token:{tenant_id}:{today}"
        used = int(await redis.get(key) or 0)

        tenant = await TenantRepository(db).get_by_id(tenant_id)
        if used + tokens > tenant.max_ai_tokens_day:
            raise QuotaExceededError(
                f"今日 AI Token 配额不足，已用 {used}，上限 {tenant.max_ai_tokens_day}"
            )
        return True

    async def record_ai_tokens(self, tenant_id: int, tokens: int, db, redis):
        """记录实际消耗的 Token（调用后写入）"""
        today = datetime.utcnow().strftime("%Y-%m-%d")
        key = f"quota:ai_token:{tenant_id}:{today}"
        await redis.incrby(key, tokens)
        await redis.expire(key, 86400)

        # 异步写入数据库统计表
        asyncio.create_task(
            self._persist_usage(tenant_id, today, tokens, db)
        )

    async def check_storage_quota(self, tenant_id: int, file_size_bytes: int, db) -> bool:
        """检查存储配额"""
        tenant = await TenantRepository(db).get_by_id(tenant_id)
        used_bytes = await FileRepository(db, tenant_id).sum_file_size()
        max_bytes = int(tenant.max_storage_gb * 1024 * 1024 * 1024)
        if used_bytes + file_size_bytes > max_bytes:
            raise QuotaExceededError(
                f"存储空间不足，已用 {used_bytes / 1e9:.2f}GB，上限 {tenant.max_storage_gb}GB"
            )
        return True
```

### 6.2 并发限制（令牌桶）

```python
# app/core/middleware/tenant_rate_limit.py

class TenantConcurrencyMiddleware(BaseHTTPMiddleware):
    """
    租户级并发控制：使用 Redis 计数器限制同一租户的并发 AI 请求数
    仅对 AI 相关接口生效
    """
    AI_PATHS = ("/api/v1/ai/",)

    async def dispatch(self, request: Request, call_next):
        if not any(request.url.path.startswith(p) for p in self.AI_PATHS):
            return await call_next(request)

        tenant_id = getattr(request.state, "tenant_id", None)
        if not tenant_id:
            return await call_next(request)

        redis = request.app.state.redis
        key = f"concurrent:{tenant_id}"
        tenant = await get_tenant_from_cache(tenant_id)
        max_concurrent = tenant.max_concurrent or 5

        current = await redis.incr(key)
        await redis.expire(key, 300)  # 5分钟兜底 TTL

        try:
            if current > max_concurrent:
                await redis.decr(key)
                return JSONResponse(
                    status_code=429,
                    content={"code": 429, "msg": "请求过于频繁，请稍后再试"}
                )
            return await call_next(request)
        finally:
            await redis.decr(key)
```

## 8. 配置中心（四级分层覆盖）

> 借鉴昊智 PaaS 配置中心设计。`config` 模块不再是简单的全局键值对，而是支持**四级覆盖**：全局默认 → 租户级覆盖 → 应用/模块级覆盖 → 用户个人级覆盖，优先级依次升高。

### 8.1 配置层级说明

| 层级 | 作用域 | 设置权限 | 示例 |
|------|--------|---------|------|
| **全局（Global）** | 平台默认值 | 超级管理员 | 系统名称、默认主题色、全局限流阈值 |
| **租户（Tenant）** | 覆盖全局，仅对本租户生效 | 租户管理员 | 租户 Logo、主题色、功能开关 |
| **应用/模块（App）** | 覆盖租户，特定模块内有效 | 租户管理员 | AI 模块的默认模型、知识库检索阈值 |
| **用户（User）** | 覆盖模块，仅对本人有效 | 用户本人 | 语言偏好、通知开关、表格列显示 |

### 8.2 数据模型

```sql
CREATE TABLE sys_config (
    id          BIGSERIAL PRIMARY KEY,
    -- 层级定位
    scope       VARCHAR(16) NOT NULL,   -- global / tenant / app / user
    tenant_id   BIGINT,                 -- scope=global 时为 NULL
    app_key     VARCHAR(64),            -- scope=app 时的模块标识，如 'ai', 'export'
    user_id     BIGINT,                 -- scope=user 时的用户 ID
    -- 配置内容
    config_key  VARCHAR(128) NOT NULL,  -- 配置键，如 'theme.primary_color'
    config_val  TEXT,                   -- 配置值（字符串，复杂值用 JSON 字符串）
    val_type    VARCHAR(16) DEFAULT 'string', -- string / int / bool / json
    is_encrypted BOOLEAN DEFAULT FALSE, -- 敏感配置加密存储
    -- 元信息
    label       VARCHAR(64),            -- 展示名称
    description TEXT,
    is_public   BOOLEAN DEFAULT FALSE,  -- 是否对前端可见（脱敏下发）
    created_at  TIMESTAMPTZ DEFAULT NOW(),
    updated_at  TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE (scope, tenant_id, app_key, user_id, config_key)
);
```

### 8.3 配置读取（四级合并逻辑）

```python
# app/modules/config_center/service.py

class ConfigCenterService:
    """
    配置读取按优先级合并：user > app > tenant > global
    利用 Redis 缓存，减少 DB 查询
    """

    async def get(
        self,
        key: str,
        *,
        tenant_id: int | None = None,
        app_key: str | None = None,
        user_id: int | None = None,
        default=None,
    ):
        # 按优先级从高到低查找
        candidates = []
        if user_id:
            candidates.append(("user", tenant_id, app_key, user_id))
        if app_key:
            candidates.append(("app", tenant_id, app_key, None))
        if tenant_id:
            candidates.append(("tenant", tenant_id, None, None))
        candidates.append(("global", None, None, None))

        for scope, tid, akey, uid in candidates:
            val = await self._get_from_cache_or_db(scope, tid, akey, uid, key)
            if val is not None:
                return val

        return default

    async def get_merged(
        self,
        keys: list[str],
        *,
        tenant_id: int | None = None,
        app_key: str | None = None,
        user_id: int | None = None,
    ) -> dict:
        """批量获取配置，返回合并后的字典（高优先级覆盖低优先级）"""
        result = {}
        # 从低优先级到高优先级叠加
        for scope, tid, akey, uid in [
            ("global", None, None, None),
            ("tenant", tenant_id, None, None),
            ("app", tenant_id, app_key, None),
            ("user", tenant_id, app_key, user_id),
        ]:
            layer = await self._get_layer(scope, tid, akey, uid, keys)
            result.update(layer)
        return result

    async def set(self, key: str, value, scope: str, **kwargs):
        """写入配置，同时使 Redis 缓存失效（Pub/Sub 广播给多实例）"""
        await self._save_to_db(scope, key, value, **kwargs)
        await self._invalidate_cache(scope, key, **kwargs)
        await self.redis.publish("config:changed", json.dumps({"scope": scope, "key": key}))
```
