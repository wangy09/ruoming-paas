# 01 快速启动

> **目标**：15 分钟内在本地跑起若茗 PaaS，看到登录界面和 API 文档。

---

## 环境要求

| 工具 | 版本要求 | 检查命令 |
|------|---------|---------|
| Docker | ≥ 24.0 | `docker --version` |
| Docker Compose | ≥ 2.20 | `docker compose version` |
| Git | 任意 | `git --version` |

> 如需本地开发（不用 Docker），另见 [本地开发模式](#本地开发模式)。

---

## 步骤一：克隆项目

```bash
git clone https://github.com/your-org/ruoming-saas.git
cd ruoming-saas
```

---

## 步骤二：配置环境变量

```bash
# 复制后端配置模板
cp backend/.env.example backend/.env.development

# 复制前端配置模板（通常不需要改）
cp frontend/.env.example frontend/.env.development
```

`.env.development` 中开箱即用的默认值已经可以直接运行，**开发阶段无需修改任何配置**。

> 如需自定义，参考 [环境变量说明](#附录-环境变量说明)。

---

## 步骤三：启动服务

```bash
# 启动所有服务（首次会拉取镜像，约 3-5 分钟）
docker compose up -d

# 查看启动状态
docker compose ps
```

正常启动后应看到以下服务均为 `running`：

```
NAME              STATUS
ruoming-postgres  running   # PostgreSQL 数据库
ruoming-redis     running   # Redis 缓存
ruoming-backend   running   # FastAPI 后端
ruoming-frontend  running   # Vue3 前端
ruoming-milvus    running   # 向量数据库（AI 功能）
```

---

## 步骤四：初始化数据库

```bash
# 执行数据库迁移（建表 + 初始化基础数据）
docker compose exec backend alembic upgrade head

# 创建初始管理员账号
docker compose exec backend python scripts/init_admin.py
```

初始账号：
- 用户名：`admin`
- 密码：`Admin@123456`（首次登录后请修改）

---

## 步骤五：访问系统

| 地址 | 说明 |
|------|------|
| `http://localhost:3000` | 前端管理界面 |
| `http://localhost:8000/docs` | API 文档（Swagger UI） |
| `http://localhost:8000/redoc` | API 文档（ReDoc） |
| `http://localhost:8000/health` | 服务健康检查 |

打开 `http://localhost:3000`，用 `admin / Admin@123456` 登录即可看到系统。

## 本地开发模式

不使用 Docker，手动启动各服务（适合开发调试）。

### 前置条件

| 工具 | 版本 |
|------|------|
| Python | 3.11+ |
| Node.js | 18+ |
| PostgreSQL | 15+ |
| Redis | 7+ |

### 后端启动

```bash
cd backend

# 安装依赖（推荐 uv）
pip install uv
uv sync

# 激活虚拟环境
source .venv/bin/activate      # Linux/macOS
# .venv\Scripts\activate       # Windows

# 配置环境变量
cp .env.example .env.development
# 修改 DATABASE_URL 和 REDIS_URL 指向本地实例

# 数据库迁移
alembic upgrade head

# 启动开发服务器（热重载）
uvicorn app.main:app --reload --port 8000
```

### 前端启动

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

## 验证安装

启动成功后，运行以下命令验证核心功能：

```bash
# 1. 健康检查
curl http://localhost:8000/health
# 期望返回：{"status": "ok", "version": "x.x.x"}

# 2. 登录获取 Token
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "Admin@123456"}'
# 期望返回：包含 access_token 的 JSON

# 3. 查看当前用户信息
curl http://localhost:8000/api/v1/auth/me \
  -H "Authorization: Bearer <上一步获取的 access_token>"
# 期望返回：admin 用户信息
```

## 常见问题

**Q：启动后前端显示空白页？**
> 等后端完全启动后再刷新（后端启动约需 10-20 秒）。可通过 `docker compose logs backend` 查看后端日志。

**Q：数据库迁移报错 `connection refused`？**
> PostgreSQL 可能还未完全启动，等待 10 秒后重试：`docker compose exec backend alembic upgrade head`

**Q：`ZHUILU_API_KEY` 未配置，AI 功能报错？**
> 如不使用追鹿模型，在 `.env.development` 中将 `AI_DEFAULT_PROVIDER` 改为 `openai`，并填写 `OPENAI_API_KEY`。AI 功能不影响其他模块正常使用。

**Q：端口冲突（3000 或 8000 已被占用）？**
> 修改 `docker-compose.yml` 中对应服务的端口映射，或停止占用端口的服务。

**Q：如何停止所有服务？**
```bash
docker compose down           # 停止并删除容器（数据保留）
docker compose down -v        # 停止并删除容器和数据卷（数据清空）
```

## 附录：环境变量说明

以下是 `.env.development` 中的关键变量（其他变量有注释说明）：

```bash
# 应用环境（development / test / production）
APP_ENV=development

# 数据库连接（使用 Docker 时保持默认即可）
DATABASE_URL=postgresql+asyncpg://ruoming:ruoming@localhost:5432/ruoming_dev

# Redis 连接
REDIS_URL=redis://localhost:6379/0

# JWT 密钥（开发环境随意填，生产环境必须是强随机值）
SECRET_KEY=dev-secret-key-change-in-production

# 默认 AI 提供商（zhuilu / openai / ollama）
AI_DEFAULT_PROVIDER=openai
OPENAI_API_KEY=sk-your-api-key-here

# 追鹿大模型（有账号则填写）
# ZHUILU_API_KEY=your-zhuilu-key
# ZHUILU_BASE_URL=https://api.zhuilu.xxx
```
