# 集成中心底座规划

## 目标

为飞书、钉钉、企业微信等协作平台提供统一底座，业务模块不直接依赖具体平台 SDK 或 API。平台切换通过连接配置完成，业务侧保持稳定调用。

## 分层

1. 业务层：消息中心、告警、审批、Agent 通知等业务只调用统一服务。
2. 集成服务层：负责租户隔离、默认连接选择、权限校验、敏感配置加解密、连通性测试。
3. 适配器层：每个平台一个 Adapter，实现统一协议。
4. 平台 API 层：封装飞书、钉钉、企业微信的真实 HTTP/API 差异。

## 当前能力

- 平台注册表：`feishu`、`dingtalk`、`wecom`。
- 连接管理：创建、更新、删除、列表、默认连接。
- 敏感配置：`webhook_url`、`app_secret` 等加密存储，接口不回显明文。
- 连通性测试：优先测试应用凭证；只有机器人 Webhook 时确认配置完整。
- 统一消息发送：业务调用 `/api/v1/integrations/messages/send`，底层自动选择连接和平台适配器。

## 后续扩展

- OAuth 登录：在适配器新增 `build_authorize_url`、`exchange_code`、`get_user_info`。
- 通讯录同步：新增同步任务表和 `sync_contacts` 能力，复用连接配置。
- 事件回调：新增回调路由，按 provider 分发到 Adapter 验签和解密。
- 审批/待办：新增能力码，不改变连接模型和业务调用方式。
- 前端管理页：在系统管理下新增集成中心页面，调用现有连接管理 API。

## 切换策略

同一租户可以维护多个平台连接，但业务默认只认启用且默认的连接。切换平台时：

1. 创建目标平台连接并完成测试。
2. 将目标连接设为默认。
3. 业务侧无需修改代码。
