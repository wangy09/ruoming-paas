# 若茗 PaaS 开发底座用户手册

> 面向基于若茗 PaaS 做二次开发、业务交付和平台管理的团队。本文先说明如何启动服务和开发模块，再介绍平台内置基础功能。适用于 2026-07 版本。

## 1. 快速开始：启动服务

### 启动开发环境

在项目根目录执行：

```bash
bash scripts/start.sh dev
```

脚本会启动 PostgreSQL、Redis、后端、Celery Worker、计划任务调度器和前端开发服务，并在首次启动时初始化菜单、角色、权限和基础数据。

常用命令：

```bash
bash scripts/start.sh status
bash scripts/start.sh logs backend
bash scripts/start.sh logs frontend
bash scripts/start.sh stop
```

### 默认访问地址

- 前端管理台：`http://localhost:3000`
- API 文档：`http://localhost:8000/api/docs`
- ReDoc：`http://localhost:8000/api/redoc`
- 健康检查：`http://localhost:8000/api/health`
- 默认账号：`admin / ruoming@2024`

首次登录后请修改默认密码。

### 初始化或补齐菜单

如果更新代码后看不到新菜单，执行初始化脚本补齐内置菜单和权限：

```bash
cd deploy
docker compose exec backend python /app/scripts/init_data.py
```

然后重新登录平台。

### 本地开发入口

- 新手启动：`docs/01_快速启动.md`
- 当前功能：`docs/当前功能清单.md`
- 新增业务模块：`docs/如何添加业务模块.md`
- API 规范：`docs/07_API规范.md`
- 前端架构：`docs/08_前端架构.md`
- 配置中心：`docs/14_配置中心设计.md`
- CI/CD：`docs/16_CICD设计.md`

## 2. 开发者指南

若茗 PaaS 的定位是开发底座，不只是后台管理系统。开发者通常围绕“启动环境 → 新增模块 → 接入菜单权限 → 联调验证 → 交付上线”这条链路工作。

### 开发目录约定

常用目录：

- `backend/app/modules/`：后端业务模块，通常包含 `models.py`、`schemas.py`、`service.py`、`router.py`。
- `backend/alembic/versions/`：数据库迁移文件。
- `backend/scripts/init_data.py`：初始化菜单、角色、权限、字典和种子数据。
- `frontend/src/views/`：页面组件，菜单组件路径会映射到这里。
- `frontend/src/api/`：前端 API 封装。
- `frontend/src/types/`：前端类型定义。
- `frontend/src/router/`：动态路由基础配置。
- `docs/`：开发文档、用户手册和功能清单。

### 新增业务模块流程

1. 设计数据表和接口边界，确认是否需要租户隔离、软删除、审计日志和数据权限。
2. 在 `backend/app/modules/<module>/` 下新增模型、Schema、Service 和 Router。
3. 在 `backend/app/main.py` 或模块聚合入口注册 Router，接口统一使用 `/api/v1/` 前缀。
4. 新增 Alembic 迁移。创建表时需要显式包含 `id`、`created_at`、`updated_at`、`is_deleted`、`tenant_id` 等基础字段。
5. 在 `frontend/src/api/` 增加接口封装。注意 Axios 拦截器返回的是业务响应对象，页面中通常直接使用 `res.data`。
6. 在 `frontend/src/views/` 新增页面，按现有 Element Plus + Vue3 组合式 API 风格实现列表、表单、详情或弹窗。
7. 在 `backend/scripts/init_data.py` 增加菜单和按钮权限，或在平台“权限中心 / 菜单管理”手工维护。
8. 在“角色授权”中给目标角色分配菜单和按钮权限，重新登录后验证侧边栏和按钮显示。
9. 运行后端编译、前端类型检查和关键接口联调。

### 菜单与权限接入

菜单由后端 `sys_permission` 数据驱动。新增页面时至少需要：

- 根菜单或上级菜单：例如 `dev`、`system`、`help`。
- 页面菜单：`perm_type=menu`，配置 `path` 和 `component`。
- 按钮权限：`perm_type=button`，例如 `order:create`、`order:update`、`order:delete`。

组件路径示例：

- 菜单 `component=system/user/index`
- 对应文件 `frontend/src/views/system/user/index.vue`

权限建议：

- 菜单权限控制页面是否可见。
- 按钮权限控制新增、编辑、删除、导出、重置密码等动作。
- 列权限控制手机号、邮箱、密钥等敏感字段是否展示。

### 配置开发

需要运行时开关、第三方地址、额度、密钥时，优先接入“平台配置 / 配置中心”。

规则：

- 敏感值设置 `is_encrypted=true`，列表和编辑回显必须脱敏。
- 公共前端配置只能从公开接口读取，且必须是已启用、非加密、`is_public=true`。
- 配置创建、更新、删除后需要清理 `config:merged:*` 缓存。
- 导入导出不能包含加密配置明文。

### 集成开发

第三方系统接入优先走“资源与集成 / 集成中心”。

建议流程：

1. 定义供应商、能力和凭证字段。
2. 敏感字段按能力动态展示。
3. 实现连接测试接口。
4. 业务功能引用连接 ID，不在业务表中重复保存密钥。
5. 对通讯录同步类能力提供自检、预览、执行和日志。

### 异步任务与计划任务

耗时任务优先使用 Celery 或计划任务。

约束：

- Celery 任务使用模块级 SQLAlchemy engine 和 sessionmaker，避免连接泄漏。
- 写日志前确保 `logs/` 目录存在。
- 计划任务统一接入“系统监控 / 计划任务”。
- 外部联系人同步类计划任务使用 `func_name + kwargs.connection_id` 去重，避免重复创建。
- 调度器启用任务时，如果 `next_run_at` 为空，只初始化下一次执行时间，不立即执行。

### 代码生成

代码生成用于生成基础业务模块代码。

关键规则：

- 写入文件需要 `dev:codegen:write` 权限。
- 生成路径禁止绝对路径和 `..` 路径穿越。
- 默认跳过已存在文件，可手动选择覆盖。
- 生成结果会返回清单，包含创建、覆盖、跳过和不可用文件数量。

建议流程：

1. 先预览生成结果。
2. 确认 Model、Schema、API、前端页面和测试路径。
3. 再执行写入。
4. 运行类型检查和后端编译检查。

### 开发验证清单

提交前建议至少执行：

```bash
PYENV_VERSION=3.11.7 python -m py_compile backend/scripts/init_data.py
cd frontend && npm run type-check
git diff --check
```

如果改了数据库：

```bash
cd backend
alembic upgrade head
```

如果改了菜单或初始化数据：

```bash
cd deploy
docker compose exec backend python /app/scripts/init_data.py
```

## 3. 登录与工作台

### 登录平台

1. 打开前端管理台地址，例如 `http://localhost:3000`。
2. 输入账号和密码。初始化环境默认超管账号为 `admin`，默认密码为 `ruoming@2024`。
3. 首次登录后请进入右上角用户菜单，修改个人密码和资料。

### 工作台

工作台聚合了当前账号可访问的常用入口、消息、公告、待关注事项和系统状态摘要。页面会按当前角色和菜单权限自动过滤入口。

常用操作：

- 点击“刷新首页”重新拉取最新数据。
- 点击“首页设置”选择首页模板、显示组件和常用入口。
- 从“常用入口”快速进入用户管理、配置中心、AI 管理、知识库、文件中心、计划任务等模块。

## 4. 平台内置基础功能

### 组织与账号

#### 用户管理

用于维护平台账号、角色、状态和外部通讯录同步。

常用操作：

- 新增用户：填写用户名、昵称、手机号、邮箱、部门、状态等信息。
- 编辑用户：更新基础资料、状态和部门信息。
- 重置密码：管理员可为用户重置登录密码。
- 分配角色：给用户授予租户管理员、普通用户或自定义角色。
- 外部联系人同步：选择飞书、钉钉、企业微信等连接，先执行“自检”和“预览”，确认变更后再执行同步。
- 同步计划任务：可为指定连接创建定时同步任务，任务会统一进入“系统监控 / 计划任务”管理。

同步建议：

- 先在“资源与集成 / 集成中心”配置并测试连接。
- 首次同步前使用“预览”确认将创建、更新或停用的用户和部门。
- 涉及部门覆盖、手机号/邮箱覆盖时，确认默认策略是否符合当前组织规则。

#### 部门管理

用于维护组织树。用户、数据权限和通讯录同步均会引用部门信息。

常用操作：

- 新增、编辑、删除部门。
- 调整上级部门和排序。
- 检查外部同步后的部门层级是否符合预期。

#### 租户管理

用于维护多租户信息、套餐、容量和状态。平台超管通常使用该模块。

常用操作：

- 创建租户并设置用户数、存储、API 调用量、AI Token 等配额。
- 启用、禁用或暂停租户。
- 查看租户联系人和审批信息。

### 权限中心

#### 角色管理

用于定义角色、数据权限范围和首页模板。

数据范围说明：

- 全部数据：可访问当前授权范围内全部数据。
- 自定义部门：按指定部门列表过滤。
- 本部门：仅访问用户所属部门数据。
- 本部门及子部门：包含下级部门数据。
- 仅本人：只能访问自己创建或归属自己的数据。

#### 角色授权

用于给角色分配菜单、按钮和列权限。保存后，用户重新登录或权限缓存刷新后生效。

操作建议：

- 先给角色授予根菜单，再授予子菜单，否则侧边栏可能无法展示完整路径。
- 对敏感操作使用按钮权限，例如删除、导出、重置密码、写入生成文件。
- 对用户列表手机号、邮箱等字段使用列权限控制可见性。

#### 菜单管理

用于维护平台路由菜单和权限点。系统内置菜单默认不可删除。

菜单字段说明：

- 路由路径：例如 `/system/users`。
- 组件路径：例如 `system/user/index`，对应 `frontend/src/views/system/user/index.vue`。
- 权限码：建议使用模块化命名，例如 `system:user:view`。
- 图标：使用 Element Plus 图标名。

### 平台配置

#### 配置中心

配置中心用于维护运行时配置，支持全局、租户、应用、用户四类作用域。

关键规则：

- 列表默认展示全局配置。
- 加密配置在列表中脱敏，编辑时留空不会覆盖原密文。
- 公开配置接口只返回已启用、非加密、`is_public=true` 的配置。
- 配置更新、删除、导入后会清理合并配置缓存。

常用操作：

- 新增配置：选择作用域、配置键、值类型、控件类型和公开状态。
- 导入/导出：用于环境迁移；加密配置不会导出明文。
- 查看历史：查看配置变更记录和操作人。
- 清缓存：手动清理 `config:merged:*` 缓存。

#### 字典管理

用于维护状态、类型、枚举值等下拉数据。

常用操作：

- 创建字典类型。
- 为字典类型维护字典项、排序和默认值。
- 停用不再使用的字典项，避免影响历史数据。

### 资源与集成

#### 文件中心

用于统一管理上传文件，支持上传、预览、下载、归档和删除。

关键规则：

- 上传扩展名必须在后端允许列表中。
- 超过大小限制会被拒绝。
- 归档用于保留文件记录但标记为不再活跃。

#### 集成中心

用于配置飞书、钉钉、企业微信和自定义集成连接。

常用操作：

- 新建连接：选择供应商和能力，例如通讯录同步、OAuth、机器人消息、事件回调。
- 填写凭证：敏感字段按能力动态展示。
- 测试连接：保存前后均建议测试。
- 设置默认连接：同一供应商可选择一个默认连接。

通讯录同步凭证要求：

- 飞书通讯录同步或 OAuth：需要 `app_id`、`app_secret`。
- 钉钉通讯录同步或 OAuth：需要 `app_key`、`app_secret`。
- 企业微信通讯录同步：需要 `corp_id`、`corp_secret`。

### AI 管理

#### AI 对话

用于直接与已配置模型或 Agent 进行对话。支持流式输出和 Markdown 展示。

#### 模型管理

用于接入大模型、Embedding 模型和 OpenAI 兼容协议模型。

操作顺序：

1. 在模型管理中创建模型配置。
2. 验证 API Key、模型 ID、基础地址和默认参数。
3. 设置默认模型或在 Agent 中绑定指定模型。

注意：Agent 初始化依赖模型配置，创建 Agent 前应先完成模型接入。

#### Agent 管理

用于创建和维护智能体。

常用配置：

- 名称、描述和头像。
- 系统提示词。
- 绑定模型。
- 工具调用和工作流配置。
- 触发方式：手动、API 或计划任务。

#### 知识库

用于维护 RAG 文档和向量索引。

支持来源：

- 本地文件上传，例如 `txt`、`md`、`pdf`、`docx`、`html`。
- URL 抓取。
- API 响应抽取。
- 数据库查询结果。

常用操作：

- 新建知识库。
- 上传或接入文档。
- 查看索引状态。
- 重新索引单个文档或整个知识库。
- 删除文档并清理向量。

#### Prompt 模板

用于维护可复用提示词，支持版本发布和回滚。

#### 工具管理

用于维护 Agent 可调用工具。工具权限和参数需要结合实际业务谨慎配置。

### 消息中心

#### 平台公告

管理员可创建、编辑、发布或删除公告。公告支持面向全部用户、部门或指定用户发布。

#### 我的消息

展示当前用户收到的站内消息。未读消息会在顶部消息铃铛中提示。

### 审计日志

#### 操作日志

记录写操作、关键接口调用、请求路径、操作者、请求结果等信息，用于问题追踪和合规审计。

#### 登录日志

记录登录行为、安全事件、设备和浏览器信息。

### 系统监控

#### 服务监控

查看后端服务、资源状态和运行指标。

#### 计划任务

统一管理定时任务和执行日志。

常用操作：

- 新增任务：选择函数、任务类型、执行间隔或 Cron 表达式。
- 启用/停用：启用后如果没有下一次执行时间，系统会先初始化下一次执行时间，不会立即执行。
- 立即执行：手动触发任务并记录日志。
- 查看日志：查看调度触发或手动触发的执行结果。

外部联系人同步任务说明：

- 同一个连接只允许创建一个同步计划任务。
- 去重逻辑使用 `func_name + kwargs.connection_id`，避免改名后重复创建。
- 调度服务使用行锁和 `SKIP LOCKED` 防止多实例重复执行。

## 5. 常见问题

### 看不到某个菜单

可能原因：

- 当前角色没有根菜单或子菜单权限。
- 菜单设置为不可见。
- 权限缓存尚未刷新，可重新登录或等待缓存过期。
- 新增菜单后未在角色授权中分配。

### 配置改了但页面没变化

检查配置是否启用、是否公开、作用域是否正确。必要时在配置中心点击“清缓存”。

### Agent 无法使用

先检查模型管理中是否已配置可用模型，再检查 Agent 是否绑定了正确模型和 Prompt。

### 通讯录同步失败

先在集成中心测试连接，再在用户管理中执行同步自检。重点检查应用凭证、通讯录权限、根部门和可见范围。

### 计划任务没有立即执行

启用计划任务时，如果 `next_run_at` 为空，调度器会先计算下一次执行时间。这是为了避免启用后立刻误触发。
